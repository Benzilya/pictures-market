# Iliano Babenchini — Private Museum

Premium multilingual portfolio and art-commerce website for contemporary artist Iliano Babenchini, Milan.

## Status

Working Next.js prototype with a responsive premium homepage.

## Stack

- Next.js 15
- React 19
- TypeScript
- CSS design system

## Local development

Requirements: Node.js 20+ and npm.

```bash
git clone https://github.com/Benzilya/pictures-market.git
cd pictures-market
npm install
npm run dev
```

Open http://localhost:3000

## Production build

```bash
npm run build
npm start
```

## Current UI

The homepage currently includes:

- premium sticky navigation
- editorial hero section
- selected works gallery
- artist statement section
- designer/collector service section
- inquiry CTA
- responsive mobile layout

Artwork surfaces are temporary visual placeholders until the final high-resolution painting assets are added.

## Brand direction

Private Museum: a digital private gallery combining museum restraint, luxury editorial design and conversion-focused art commerce.
